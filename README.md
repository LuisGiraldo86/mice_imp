# Approaches for measurement calibration in the presence of planned-missing data: a semi-simulation head-to-head comparison of WD-FAB-DE data

## Abstract

**Objective:** Planned-missing data designs administer a subset of a measure to each respondent, therefore reducing respondent burden during item response theory (IRT) calibration. Several approaches to calibration in the presence of missing data are available. Stacking-based imputation approach that combines pairwise response predictors with latent-variable fallbacks, allowing the same model to be used during calibration and computerized adaptive testing (CAT), is an innovative approach to currently existing calibration approaches. The aim of this study is to inform the methodology of the ongoing German Work Disability Functional Assessment Battery (WD-FAB-DE) calibration study.

**Methods:** In this study, we conduct a head-to-head assessment of this approach alongside four alternative approaches using applied masking study of the Community Mobility scale (CM) of the WD-FAB-DE. Three planned-missing data designs were simulated for the CM scale. Five calibration approaches were implemented on the full-data as well as simulated missing data: full-information maximum likelihood (FIML), multi-group IRT, Stocking-Lord scale linking, Bayesian IRT (B-IRT), and multiple imputation plus B-IRT (M+B-IRT). Differences between person-score estimates from simulated-missing and the full-form dataset were quantified using mean-squared error, root mean-squared error and Bland-Altman graphs. Item parameters were evaluated by comparing the alignment between simulated planned-missing and full-form estimates (regression and correlation coefficients).

**Results:** Agreement with the full-form reference were similar across all calibration approaches except for MI+B-IRT, which showed a different tradeoff between person-score and item-parameter agreement. The small differences in agreement (RMSE 0.219-0.342, regression coefficients 0.652-1.614, correlation coefficients 0.974-0.995) indicated that when comparing to data without planned-missing, the assessed approaches will result in similar calibrations.

**Conclusions:** Due to similarities across all evaluated calibration approaches, the simplest to implement approach (FIML) will be used for the first WD-FAB-DE calibration. MI+B-IRT may offer modest, design-dependent gains in other settings, and needs further testing for deployment in health measurement using CAT.
